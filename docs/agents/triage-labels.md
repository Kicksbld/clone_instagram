# Labels de triage

Les skills parlent de cinq rôles de triage. Ce dépôt garde les noms par défaut.

| Label dans mattpocock/skills | Label dans ce dépôt | Sens |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | À évaluer par le lead dev |
| `needs-info` | `needs-info` | En attente d'informations |
| `ready-for-agent` | `ready-for-agent` | Entièrement spécifiée, prête pour un agent |
| `ready-for-human` | `ready-for-human` | Demande une intervention humaine |
| `wontfix` | `wontfix` | Ne sera pas traitée |

Labels propres au projet : `phase` (plan de phase, parent des tranches), `wayfinder:*` (cartes `/wayfinder`).
